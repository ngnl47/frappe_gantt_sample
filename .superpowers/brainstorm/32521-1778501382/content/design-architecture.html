设计第一部分：项目架构

目录结构与模块划分

项目目录结构
frappe_gantt_sample/
├── src/
│   ├── main.ts                 # 入口文件
│   ├── App.vue                 # 根组件
│   ├── assets/
│   │   └── styles/
│   │       └── main.scss       # 全局样式
│   ├── components/
│   │   ├── GanttChart.vue      # 甘特图组件（封装 Frappe Gantt）
│   │   ├── TaskModal.vue       # 任务详情/编辑弹窗
│   │   └── Toolbar.vue         # 顶部工具栏
│   ├── services/
│   │   ├── database.ts         # IndexedDB 操作封装
│   │   ├── dataService.ts      # 数据 CRUD 业务逻辑
│   │   └── ganttAdapter.ts     # 甘特图数据适配器
│   ├── stores/
│   │   └── ganttStore.ts       # Pinia 状态管理
│   ├── types/
│   │   └── index.ts            # TypeScript 类型定义
│   ├── data/
│   │   └── presetData.ts       # 预设示例数据
│   ├── utils/
│   │   └── timeUtils.ts        # 时间处理工具
│   └── views/
│   │   └── GanttView.vue       # 主页面视图
│   └── router/
│       └── index.ts            # 路由配置（可选，单页面可简化）
├── public/
├── index.html
├── package.json
├── vite.config.ts
├── tailwind.config.js
└── tsconfig.json
架构特点：
  • 单页面应用，路由简化（可不用 Vue Router）
  • 数据层与服务层分离，便于移植到 evo-manager
  • Frappe Gantt 通过适配器转换为业务数据格式
