方案对比：甘特图数据映射与页面布局

基于 Frappe Gantt 的特性，有几种不同的实现思路：

方案 A：甘特图为主 + 底部表格
操作栏（新增、时间范围筛选）
甘特图（主体区域）
底部数据列表表格（可选）

优点

  • 甘特图核心展示直观
  • 适合单一功能 demo

缺点

  • 表格与甘特图分离
方案 B：左侧列表 + 右侧甘特图
数据列表（可折叠）
甘特图

优点

  • 数据与甘特图同步显示

缺点

  • 布局复杂
  • 甘特图区域受限
方案 C：甘特图单页面 + 弹窗（推荐）
[新增] [时间范围筛选] [重置]
甘特图（全屏展示）

点击任务块 → 弹窗显示详情 + 编辑

优点

  • 最简洁，甘特图最大化
  • 符合 demo 简化需求
  • 移植后可扩展

缺点

  • 缺少表格视图

推荐：方案 C — Demo 目的是验证可行性，甘特图最大化可视区域，弹窗编辑满足单条增删改查。
