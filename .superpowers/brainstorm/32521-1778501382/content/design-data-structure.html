设计第二部分：数据结构设计

业务数据与甘特图数据的转换

业务数据类型（TypeScript）
// 数据类型枚举
export enum DataType {
  MAPPING = 1,    // 服务器映射指向关系
  PAUSED = 2      // 服务器暂停期，无指向
}

// 单条记录数据结构（与你提供的 JSON 对应）
export interface ServerMapping {
  id: number;         // 记录唯一 ID，全局自增
  k: number;          // 源服务器 ID
  v: number | null;   // 目标服务器 ID，null=暂停期
  cmt: string;        // 备注
  ct: number;         // 创建时间（毫秒时间戳）
  st: number;         // 开始时间（毫秒时间戳）
  et: number;         // 结束时间（毫秒时间戳）
  type: DataType;     // 数据类型
}
甘特图任务块类型
// Frappe Gantt 任务块格式
export interface GanttTask {
  id: string;         // 格式：`${k}_${st}_${et}`
  name: string;       // 显示名称：服务器 ID
  start: string;      // ISO 格式时间
  end: string;        // ISO 格式时间
  progress: number;   // 默认 0（暂不使用）
  dependencies: string; // 依赖的任务块 ID
  custom_class?: string; // CSS 类：task-mapping/task-paused
  _serverId: number;  // 扩展：服务器 ID
  _mappingId: number; // 扩展：业务数据 ID
}
数据转换规则
业务字段 甘特图字段 转换规则
k id 前缀 任务块 ID = `${k}_${st}_${et}`
k name 显示为服务器 ID
st/et start/end dayjs 转为 ISO 格式
v dependencies type=1 且 v≠null 时，依赖 = `${v}_${st}_${et}`
type custom_class 1 → 'task-mapping'，2 → 'task-paused'
关键约束校验：
  • 相同服务器的时间段不能重叠（[st, et] 不能交叉）
  • 有指向关系的两个任务块，st 与 et 必须一致
  • 被指向的任务块必须先存在（录入时校验）
